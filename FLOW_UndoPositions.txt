                     UNDO POSITIONS SYSTEM - FLUJO COMPLETO
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN:
  - Sistema revolucionario para revertir posiciones de fondos de inversión
  - Permite a los inversores "deshacer" cualquier operación y recuperar su dinero
  - Arquitectura modular que funciona con cualquier tipo de posición
  - Integración nativa con el protocolo existente de UpgradeableLib

DEPENDENCIAS:
  - UpgradeableLib (registro de positionTypes)
  - ProtocolStorage (datos de posiciones)
  - DecoderLib (decodificación de parámetros)
  - IERC20 (transferencias de tokens)

PROTECCIÓN:
  - Solo el owner de la posición puede ejecutar undo
  - Validación de instrucciones antes de ejecución
  - Límites de gas para prevenir DoS
  - Manejo de errores con rollback automático

═══════════════════════════════════════════════════════════════════════════════
                    ¿QUÉ PROBLEMA RESUELVE?
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA ACTUAL:
  Los fondos de inversión tradicionales tienen un problema fundamental:
  una vez que el gestor del fondo toma una posición, los inversores no pueden
  recuperar su dinero hasta que el fondo decida cerrar la posición.

NUESTRA SOLUCIÓN:
  Cada posición que se abre en el protocolo incluye automáticamente un conjunto
  de "instrucciones de deshacer" que permiten al inversor revertir la operación
  en cualquier momento y recuperar su capital original.

EJEMPLO REAL:
  - Inversor deposita 1 ETH en un fondo
  - Fondo abre posición Long en ETH con 10x leverage
  - Si el precio baja, el inversor puede ejecutar undo() y recuperar su 1 ETH
  - No necesita esperar a que el fondo decida cerrar la posición

BENEFICIOS:
  ✓ TRANSPARENCIA: Los inversores saben exactamente cómo pueden salir
  ✓ SEGURIDAD: Reducción drástica del riesgo de pérdida total
  ✓ CONFIANZA: Los inversores confían más en fondos con esta funcionalidad
  ✓ COMPETITIVIDAD: Ventaja sobre fondos tradicionales sin esta capacidad

═══════════════════════════════════════════════════════════════════════════════
                    ARQUITECTURA DEL SISTEMA
═══════════════════════════════════════════════════════════════════════════════

1. REGISTRO DE INSTRUCCIONES:
   │
   ├─ En UpgradeableLib.positionTypes se añade campo:
   │   │
   │   └─ undoInstructions: bytes[]  ← NUEVO CAMPO
   │
   ├─ Cuando se registra un nuevo tipo de posición:
   │   │
   │   └─ registerPositionType(
   │           typeId,
   │           typeName,
   │           undoInstructions    ← Instrucciones para deshacer
   │       )
   │
   └─ Ejemplo de registro:
       registerPositionType(
           0,                          // Market Neutral
           "MarketNeutral",
           encodeInstructions([...])   // Ver estructura abajo
       )

2. ESTRUCTURA DE INSTRUCCIONES:
   │
   └─ bytes[] undoInstructions contiene:
       │
       ├─ [0] uint[] actionTypes     // 0=sendEth, 1=sendToken, 2=callFunction
       ├─ [1] address[] contracts    // Contratos a interactuar
       ├─ [2] string[] functions     // Funciones a llamar (para encodeWithSelector)
       ├─ [3] uint[] paramTypes      // Tipos de parámetros (como ProtocolLib)
       └─ [4] bytes[] params         // Valores de parámetros

3. EJECUCIÓN DE UNDO:
   │
   ├─ Inversor llama: undo(positionId)
   ├─ Sistema decodifica instrucciones del positionType
   ├─ Valida que el inversor es owner de la posición
   ├─ Ejecuta cada instrucción en secuencia
   └─ Transfiere fondos de vuelta al inversor

═══════════════════════════════════════════════════════════════════════════════
                      TIPOS DE ACCIÓN SOPORTADOS
═══════════════════════════════════════════════════════════════════════════════

┌─────────────┬─────────────────────────────────────────────────────────────────┐
│ ActionType  │ Descripción y Uso                                              │
├─────────────┼─────────────────────────────────────────────────────────────────┤
│ 0 - sendEth │ Transfiere ETH directamente al inversor                        │
│             │ params[0] = cantidad en wei                                    │
│             │ Ejemplo: Devolver colateral ETH de una posición                │
├─────────────┼─────────────────────────────────────────────────────────────────┤
│ 1 - sendToken│ Transfiere tokens ERC20 al inversor                           │
│             │ contracts[0] = address del token                               │
│             │ params[0] = cantidad en unidades del token                     │
│             │ Ejemplo: Devolver USDC de una posición short                   │
├─────────────┼─────────────────────────────────────────────────────────────────┤
│ 2 - callFunction│ Llama función en contrato externo                          │
│             │ contracts[0] = address del contrato                            │
│             │ functions[0] = "functionName(type1,type2)"                     │
│             │ params[0] = parámetros encodados                               │
│             │ Ejemplo: Cerrar posición en GMX automáticamente                │
├─────────────┼─────────────────────────────────────────────────────────────────┤
│ 3 - callPayableFunction│ Igual que callFunction pero con msg.value           │
│             │ Ejemplo: Llamar función que requiere ETH para gas              │
└─────────────┴─────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════
                    EJEMPLO: MARKET NEUTRAL UNDO
═══════════════════════════════════════════════════════════════════════════════

POSICIÓN ORIGINAL:
  - Inversor deposita: 2 ETH
  - Fondo abre: Long ETH (1 ETH colateral) + Short BTC (1 ETH colateral)
  - Posición registrada con undoInstructions

INSTRUCCIONES DE UNDO:
  bytes[] instructions = [
      [2, 2],                                    // actionTypes: [callFunction, callFunction]
      [gmxAddress, gmxAddress],                  // contracts: [GMX, GMX]
      ["closePosition(uint256,uint256,uint256)", // functions: [closeLong, closeShort]
       "closePosition(uint256,uint256,uint256)"],
      [1, 1, 1, 1, 1, 1],                       // paramTypes: [uint, uint, uint] x2
      [encode([positionIdLong, 0, 0]),          // params: [long params, short params]
       encode([positionIdShort, 0, 0])]
  ];

FLUJO DE EJECUCIÓN:
  Inversor → undo(positionId)
    │
    ├─ PASO 1: Validaciones
    │   ├─ Verificar que msg.sender es owner de positionId
    │   ├─ Verificar que posición está activa
    │   └─ Verificar que undoInstructions existen
    │
    ├─ PASO 2: Decodificar instrucciones
    │   ├─ positionType = getPositionType(positionId)
    │   ├─ instructions = positionType.undoInstructions
    │   └─ Decodificar arrays: actionTypes, contracts, functions, paramTypes, params
    │
    ├─ PASO 3: Ejecutar acciones
    │   │
    │   ├─ Acción 0: callFunction
    │   │   ├─ Contrato: GMX
    │   │   ├─ Función: "closePosition(uint256,uint256,uint256)"
    │   │   ├─ Parámetros: [positionIdLong, 0, 0]
    │   │   └─ Resultado: Posición Long cerrada, ETH devuelto al protocolo
    │   │
    │   └─ Acción 1: callFunction
    │       ├─ Contrato: GMX
    │       ├─ Función: "closePosition(uint256,uint256,uint256)"
    │       ├─ Parámetros: [positionIdShort, 0, 0]
    │       └─ Resultado: Posición Short cerrada, ETH devuelto al protocolo
    │
    └─ PASO 4: Transferir fondos al inversor
        │
        └─ Los ETH devueltos por GMX se transfieren automáticamente
            al inversor via callback o transferencia directa

RESULTADO:
  ✓ Posición Long cerrada en GMX
  ✓ Posición Short cerrada en GMX  
  ✓ 2 ETH devueltos al inversor (capital original)
  ✓ Posición marcada como cerrada en ProtocolStorage
  ✓ PnL calculado y registrado

═══════════════════════════════════════════════════════════════════════════════
                      IMPLEMENTACIÓN TÉCNICA
═══════════════════════════════════════════════════════════════════════════════

FUNCIÓN PRINCIPAL:
  function undo(bytes32 positionId) public {
      // PASO 1: Validaciones
      require(positions[positionId].owner == msg.sender, "Not position owner");
      require(positions[positionId].isActive, "Position not active");
      
      // PASO 2: Obtener instrucciones
      uint128 positionType = positions[positionId].positionType;
      bytes[] memory instructions = getPositionType(positionType).undoInstructions;
      require(instructions.length > 0, "No undo instructions");
      
      // PASO 3: Decodificar instrucciones
      bytes[] memory decodedInstructions = abi.decode(instructions, (bytes[]));
      uint[] memory actionTypes = abi.decode(decodedInstructions[0], (uint[]));
      address[] memory contracts = abi.decode(decodedInstructions[1], (address[]));
      string[] memory functions = abi.decode(decodedInstructions[2], (string[]));
      uint[] memory paramTypes = abi.decode(decodedInstructions[3], (uint[]));
      bytes[] memory params = abi.decode(decodedInstructions[4], (bytes[]));
      
      // PASO 4: Ejecutar acciones
      for(uint i = 0; i < actionTypes.length; i++) {
          if(actionTypes[i] == 0) {
              // sendEth
              uint256 amount = abi.decode(params[i], (uint256));
              payable(msg.sender).transfer(amount);
              
          } else if(actionTypes[i] == 1) {
              // sendToken
              address tokenAddress = contracts[i];
              uint256 amount = abi.decode(params[i], (uint256));
              IERC20(tokenAddress).transfer(msg.sender, amount);
              
          } else if(actionTypes[i] == 2) {
              // callFunction
              address contractAddress = contracts[i];
              string memory functionSignature = functions[i];
              bytes memory functionParams = params[i];
              
              (bool success, ) = contractAddress.call(
                  abi.encodeWithSelector(
                      bytes4(keccak256(bytes(functionSignature))),
                      functionParams
                  )
              );
              require(success, "Function call failed");
              
          } else if(actionTypes[i] == 3) {
              // callPayableFunction
              address contractAddress = contracts[i];
              string memory functionSignature = functions[i];
              bytes memory functionParams = params[i];
              uint256 value = abi.decode(params[i], (uint256));
              
              (bool success, ) = contractAddress.call{value: value}(
                  abi.encodeWithSelector(
                      bytes4(keccak256(bytes(functionSignature))),
                      functionParams
                  )
              );
              require(success, "Payable function call failed");
          }
      }
      
      // PASO 5: Marcar posición como cerrada
      positions[positionId].isActive = false;
      emit PositionUndone(positionId, msg.sender, block.timestamp);
  }

VALIDACIONES DE SEGURIDAD:
  ✓ Solo el owner puede ejecutar undo
  ✓ Posición debe estar activa
  ✓ Instrucciones deben existir
  ✓ Límite de gas para prevenir DoS
  ✓ Validación de contratos externos
  ✓ Manejo de errores con rollback
