                  GMXMARKETSREGISTRY.SOL - FLUJO COMPLETO
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN:
  - Registry centralizado de direcciones de mercados GMX V2
  - Mapea símbolos legibles a addresses de contratos
  - Upgradeable por admins si GMX cambia addresses

DEPENDENCIAS:
  - Roles (autenticación de admins)

PROPÓSITO:
  - Abstracción: Frontend usa "ETHUSDC" en vez de 0x70d95...
  - Mantenibilidad: Si GMX cambia address, solo se actualiza aquí
  - Seguridad: Solo admins pueden modificar addresses

═══════════════════════════════════════════════════════════════════════════════
                     OBTENER MERCADO (Principal)
═══════════════════════════════════════════════════════════════════════════════

Frontend/Main → getMarket("ETHUSDC") → address
  │
  ├─ PASO 1: Crear hash del símbolo
  │   │
  │   └─ symbolHash = keccak256(abi.encode("ETHUSDC"))
  │       │
  │       └─ Hash único por símbolo
  │
  ├─ PASO 2: Buscar en mapping
  │   │
  │   └─ marketAddress = markets[symbolHash]
  │       │
  │       └─ Retorna: 0x70d95587d40A2caf56bd97485aB3Eec10Bee6336
  │
  ├─ PASO 3: Validar existe
  │   │
  │   └─ require(marketAddress != address(0), "Market not found")
  │
  └─ RETORNO:
      └─ address del mercado GMX


EJEMPLO USO:

  Main.openMarketNeutral("ETHUSDC", "BTCUSDC", ...)
    │
    ├─ address ethMarket = gmxMarkets.getMarket("ETHUSDC")
    │   └─ 0x70d95587d40A2caf56bd97485aB3Eec10Bee6336
    │
    └─ address btcMarket = gmxMarkets.getMarket("BTCUSDC")
        └─ 0x47c031236e19d024b42f8AE6780E44A573170703


═══════════════════════════════════════════════════════════════════════════════
                     AÑADIR MERCADO (ADMIN)
═══════════════════════════════════════════════════════════════════════════════

Admin → addMarket("NEWUSDC", 0xNew...Address)
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │   │
  │   └─ roles.checkAdmin(msg.sender)
  │       ├─ SI TRUE: ✓ Continúa
  │       └─ SI FALSE: ✗ REVERT "Not admin"
  │
  ├─ VALIDACIÓN 2: Address válida
  │   └─ require(marketAddress != address(0), "Invalid address")
  │
  ├─ PASO 1: Crear hash del símbolo
  │   │
  │   └─ symbolHash = keccak256(abi.encode("NEWUSDC"))
  │
  ├─ PASO 2: Guardar en mappings
  │   │
  │   ├─ markets[symbolHash] = 0xNew...Address
  │   └─ marketExists[symbolHash] = true
  │
  └─ PASO 3: Emitir evento (opcional)
      │
      └─ emit MarketAdded("NEWUSDC", 0xNew...Address)


RESULTADO:
  ✓ Nuevo mercado disponible inmediatamente
  ✓ getMarket("NEWUSDC") funciona
  ✓ Frontend puede usar el nuevo símbolo


═══════════════════════════════════════════════════════════════════════════════
                     ACTUALIZAR MERCADO (ADMIN)
═══════════════════════════════════════════════════════════════════════════════

Admin → updateMarket("ETHUSDC", 0xNewETH...Address)
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │
  ├─ VALIDACIÓN 2: Mercado existe
  │   │
  │   └─ symbolHash = keccak256(abi.encode("ETHUSDC"))
  │       require(marketExists[symbolHash], "Market not found")
  │
  ├─ PASO 1: Actualizar address
  │   │
  │   └─ markets[symbolHash] = 0xNewETH...Address
  │
  └─ PASO 2: Emitir evento
      │
      └─ emit MarketUpdated("ETHUSDC", oldAddress, newAddress)


CASO DE USO:
  
  GMX actualiza el contrato de mercado ETH/USDC
  │
  └─ Admin detecta el cambio
      │
      └─ updateMarket("ETHUSDC", nuevoAddress)
          │
          └─ Protocolo usa automáticamente el nuevo address
              ✓ Sin necesidad de redeployar Main.sol
              ✓ Sin downtime del protocolo


═══════════════════════════════════════════════════════════════════════════════
                     ELIMINAR MERCADO (ADMIN)
═══════════════════════════════════════════════════════════════════════════════

Admin → removeMarket("OLDUSDC")
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │
  ├─ VALIDACIÓN 2: Mercado existe
  │   └─ require(marketExists[symbolHash], "Market not found")
  │
  ├─ PASO 1: Eliminar de mappings
  │   │
  │   ├─ markets[symbolHash] = address(0)
  │   └─ marketExists[symbolHash] = false
  │
  └─ PASO 2: Emitir evento
      │
      └─ emit MarketRemoved("OLDUSDC")


RESULTADO:
  ✗ getMarket("OLDUSDC") revierte con "Market not found"
  ✗ No se pueden abrir nuevas posiciones en ese mercado
  ✓ Posiciones existentes NO se afectan

═══════════════════════════════════════════════════════════════════════════════
                     ESTRUCTURA DE DATOS
═══════════════════════════════════════════════════════════════════════════════

mapping(bytes32 => address) public markets
  │
  └─ Key: keccak256(abi.encode("ETHUSDC"))
      Value: 0x70d95587d40A2caf56bd97485aB3Eec10Bee6336

mapping(bytes32 => bool) public marketExists
  │
  └─ Key: keccak256(abi.encode("ETHUSDC"))
      Value: true


VENTAJAS DEL HASH:
  ✓ Gas efficient (bytes32 vs string storage)
  ✓ Collision resistant (keccak256)
  ✓ Consistent (mismo string → mismo hash siempre)
