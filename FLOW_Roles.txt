                         ROLES.SOL - FLUJO COMPLETO
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN:
  - Sistema de control de acceso con gobernanza democrática
  - Gestiona admins y contratos autorizados del protocolo
  - Implementa consensus de 2-de-3 para decisiones críticas

CARACTERÍSTICAS:
  - 3 admins iniciales (immutable)
  - Sistema de aprobación democrática (2/3 required)
  - Whitelist de contratos del protocolo
  - Sistema de penalización de admins
  - Previene single point of failure

═══════════════════════════════════════════════════════════════════════════════
                     INICIALIZACIÓN (CONSTRUCTOR)
═══════════════════════════════════════════════════════════════════════════════

Deploy → new Roles(mainAdmin, admin2, admin3)
  │
  ├─ VALIDACIONES:
  │   ├─ mainAdmin != address(0) ✓
  │   ├─ admin2 != address(0) ✓
  │   ├─ admin3 != address(0) ✓
  │   ├─ mainAdmin != admin2 != admin3 ✓ (todos únicos)
  │   └─ SI falla: REVERT "InvalidSigner"
  │
  ├─ SETUP IMMUTABLE:
  │   ├─ mainAdmin = _mainAdmin (immutable forever)
  │   ├─ admin2 = _admin2 (immutable forever)
  │   └─ admin3 = _admin3 (immutable forever)
  │
  ├─ ACTIVAR ADMINS:
  │   ├─ isAdmin[mainAdmin].isAdmin = true
  │   ├─ isAdmin[admin2].isAdmin = true
  │   └─ isAdmin[admin3].isAdmin = true
  │
  └─ AÑADIR A ARRAY:
      ├─ admins.push(mainAdmin)
      ├─ admins.push(admin2)
      └─ admins.push(admin3)


RESULTADO:
  ✓ 3 admins activos desde el inicio
  ✓ Addresses immutables (no se pueden cambiar)
  ✓ Sistema listo para aprobar contratos


═══════════════════════════════════════════════════════════════════════════════
                     APROBAR CONTRATO (Consensus 2/3)
═══════════════════════════════════════════════════════════════════════════════

Admin1 → allowContract(contractAddress, "Main")
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │   └─ isAdmin[msg.sender].isAdmin == true ✓
  │
  ├─ VALIDACIÓN 2: Es contrato válido
  │   ├─ contractAddress != address(0) ✓
  │   └─ isContractAddress(contractAddress) ✓
  │       │
  │       └─ extcodehash != 0 && extcodehash != emptyHash
  │
  ├─ VALIDACIÓN 3: No ha aprobado antes
  │   └─ checkApprovals(isProtocol[contract].approvedBy)
  │       │
  │       └─ Loop por approvedBy[]
  │           ├─ SI msg.sender YA aprobó: REVERT
  │           └─ SI NO ha aprobado: Continúa ✓
  │
  ├─ SI approvals >= 2:
  │   │
  │   └─ ✓ CONTRATO ACTIVADO
  │       │
  │       └─ isProtocol[contract] = Contract{
  │               isProtocol: true,
  │               name: "Main",
  │               approvals: 2 (o más),
  │               approvedBy: [admin1, admin2]
  │           }
  │
  └─ SI approvals < 2:
      │
      └─ ⏳ PENDIENTE DE APROBACIÓN
          │
          └─ isProtocol[contract].approvals++
              isProtocol[contract].approvedBy.push(msg.sender)


FLUJO COMPLETO:

  Estado inicial:
    approvals = 0
    approvedBy = []
    isProtocol = false

  Admin1 aprueba:
    └─ allowContract(Main, "Main")
        ├─ approvals = 1
        ├─ approvedBy = [admin1]
        └─ isProtocol = false ⏳

  Admin2 aprueba:
    └─ allowContract(Main, "Main")
        ├─ approvals = 2
        ├─ approvedBy = [admin1, admin2]
        └─ isProtocol = true ✓ ACTIVADO

  Main ahora puede:
    ├─ Llamar BundlesRouter.route() ✓
    ├─ Llamar ProtocolStorage.updateUser() ✓
    └─ Todas las funciones onlyProtocol ✓


═══════════════════════════════════════════════════════════════════════════════
                     ELIMINAR CONTRATO
═══════════════════════════════════════════════════════════════════════════════

Admin → deleteContract(contractAddress)
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │
  ├─ VALIDACIÓN 2: Contrato existe y está activo
  │   └─ isProtocol[contract].isProtocol == true
  │
  └─ DESACTIVAR:
      └─ isProtocol[contract].isProtocol = false


RESULTADO:
  ✗ Contrato ya no puede acceder funciones onlyProtocol
  ✗ Todas sus llamadas serán rechazadas


NOTA: Solo 1 admin puede eliminar (no requiere consensus)
  - Medida de emergencia para respuesta rápida
  - Si hay desacuerdo, se puede re-aprobar


═══════════════════════════════════════════════════════════════════════════════
                     PROPONER NUEVO ADMIN (Consensus 2/3)
═══════════════════════════════════════════════════════════════════════════════

Admin1 → proposeAdmin(newAdminAddress)
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │
  ├─ VALIDACIÓN 2: Address válida
  │   └─ newAdminAddress != address(0)
  │
  ├─ VALIDACIÓN 3: No es admin ya
  │   └─ !isAdmin[newAdminAddress].isAdmin
  │
  ├─ VALIDACIÓN 4: No ha aprobado antes
  │   └─ checkAdminApprovals(isAdmin[newAdmin].approvedBy)
  │
  ├─ Añadir aprobación:
  │   ├─ isAdmin[newAdmin].approvals++
  │   └─ isAdmin[newAdmin].approvedBy.push(msg.sender)
  │
  └─ SI approvals >= 2:
      │
      └─ ✓ ADMIN ACTIVADO
          ├─ isAdmin[newAdmin].isAdmin = true
          └─ admins.push(newAdmin)


FLUJO COMPLETO:

  Admin1 propone:
    └─ proposeAdmin(0xNew)
        ├─ approvals = 1
        ├─ approvedBy = [admin1]
        └─ isAdmin = false ⏳

  Admin2 aprueba:
    └─ proposeAdmin(0xNew)
        ├─ approvals = 2
        ├─ approvedBy = [admin1, admin2]
        └─ isAdmin = true ✓

  Ahora hay 4 admins:
    ├─ mainAdmin (original)
    ├─ admin2 (original)
    ├─ admin3 (original)
    └─ newAdmin (añadido)


═══════════════════════════════════════════════════════════════════════════════
                     PENALIZAR ADMIN (Consensus 2/3)
═══════════════════════════════════════════════════════════════════════════════

Admin1 → penalizeAdmin(compromisedAdmin)
  │
  ├─ VALIDACIÓN 1: onlyAdmin
  │
  ├─ VALIDACIÓN 2: No auto-penalización
  │   └─ compromisedAdmin != msg.sender
  │
  ├─ VALIDACIÓN 3: No ha penalizado antes
  │   └─ Loop por isAdmin[compromisedAdmin].penalizedBy
  │       ├─ SI msg.sender ya penalizó: REVERT
  │       └─ SI NO: Continúa ✓
  │
  ├─ Añadir penalización:
  │   ├─ isAdmin[compromisedAdmin].penalizedBy.push(msg.sender)
  │   └─ isAdmin[compromisedAdmin].penalties++
  │
  └─ SI penalties >= 2:
      │
      └─ removeAdmin(compromisedAdmin)
          │
          ├─ isAdmin[compromisedAdmin].isAdmin = false
          │
          └─ Remove from admins[] array
              ├─ Find index
              ├─ Swap with last element
              └─ Pop()


EJEMPLO (Admin comprometido):

  Admin2 sospecha de admin3:
    └─ penalizeAdmin(admin3)
        ├─ penalties = 1
        ├─ penalizedBy = [admin2]
        └─ Aún es admin ⚠️

  Admin1 también sospecha:
    └─ penalizeAdmin(admin3)
        ├─ penalties = 2
        ├─ penalizedBy = [admin2, admin1]
        └─ removeAdmin(admin3) ✗
            └─ admin3 ya NO es admin

  Resultado:
    ✗ admin3 eliminado del sistema
    ✓ mainAdmin y admin2 continúan
    ✓ Pueden proponer nuevo admin

  - MarketNeutral.execute() → modifier onlyProtocol


checkAdmin(address) → bool
  │
  └─ isAdmin[address].isAdmin
      │
      ├─ TRUE: Es admin ✓
      └─ FALSE: NO es admin ✗

═══════════════════════════════════════════════════════════════════════════════
                     ESTRUCTURA DE DATOS
═══════════════════════════════════════════════════════════════════════════════

struct Contract {
    bool isProtocol;         // true = activo, false = inactivo
    string name;             // Identificador legible
    uint256 approvals;       // Cuenta de aprobaciones
    address[] approvedBy;    // Quién aprobó
}

struct Admin {
    bool isAdmin;            // true = activo
    uint256 approvals;       // Para nuevos admins
    uint256 penalties;       // Cuenta de penalizaciones
    address[] approvedBy;    // Quién aprobó (para nuevos)
    address[] penalizedBy;   // Quién penalizó
}
