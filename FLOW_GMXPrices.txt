═══════════════════════════════════════════════════════════════════════════════
                       GMXPRICES.SOL - FLUJO COMPLETO
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN:
  - Oracle de precios integrado con GMX V2 DataStore
  - Obtiene precios de Chainlink via GMX infrastructure
  - Calcula precios aceptables con protección de slippage

DEPENDENCIAS:
  - GMX IDataStore (lee configuración de mercados)
  - Chainlink Price Feeds (precios en tiempo real)
  - PricesLib (utilidades de precios)

CONSTANTES:
  - GMX_PRICE_DECIMALS: 30 (formato interno de GMX)
  - DEFAULT_SLIPPAGE_BPS: 50 (0.5% slippage default)

═══════════════════════════════════════════════════════════════════════════════
                     OBTENER PRECIO ACEPTABLE (Principal)
═══════════════════════════════════════════════════════════════════════════════

Main → getAcceptablePrice(
         marketAddress,    // Dirección del mercado GMX
         isLong,          // true=Long, false=Short
         isIncrease,      // true=Abrir, false=Cerrar
         slippageBps      // Tolerancia (ej: 50 = 0.5%)
       )
  │
  ├─ PASO 1: Obtener precio actual de Chainlink
  │   │
  │   └─ getMarketPriceWithDecimals(marketAddress)
  │       │
  │       ├─ getMarket(marketAddress) → Market struct
  │       │   │
  │       │   └─ Lee desde GMX DataStore:
  │       │       ├─ indexToken (ej: WETH)
  │       │       ├─ longToken (ej: WETH)
  │       │       └─ shortToken (ej: USDC)
  │       │
  │       ├─ getChainlinkPriceFeed(market.indexToken)
  │       │   │
  │       │   └─ GMX DataStore: PRICE_FEED key
  │       │       └─ Retorna: address del Chainlink feed
  │       │
  │       └─ PricesLib.getPriceWithDecimals(priceFeed)
  │           │
  │           └─ Chainlink.latestRoundData()
  │               └─ Retorna: (price, decimals)
  │                   Ejemplo: (1800 * 10^8, 8) para ETH
  │
  ├─ PASO 2: Convertir a formato GMX (30 decimales)
  │   │
  │   └─ currentPrice = toGMXPrice(rawPrice, decimals)
  │       │
  │       └─ Formula: price * 10^(30 - decimals)
  │           │
  │           └─ Ejemplo:
  │               Input:  1800 * 10^8 (8 decimals)
  │               Output: 1800 * 10^30 (30 decimals)
  │
  ├─ PASO 3: Calcular slippage
  │   │
  │   └─ slippageAmount = (currentPrice * slippageBps) / 10000
  │       │
  │       └─ Ejemplo:
  │           currentPrice = 1800 * 10^30
  │           slippageBps = 50 (0.5%)
  │           slippageAmount = (1800 * 10^30 * 50) / 10000
  │                          = 9 * 10^29 (0.5% de 1800)
  │
  └─ PASO 4: Aplicar slippage según tipo de operación
      │
      ├─ SI isIncrease (Abriendo posición):
      │   │
      │   ├─ SI isLong (Comprando):
      │   │   │
      │   │   └─ acceptablePrice = currentPrice + slippageAmount
      │   │       │
      │   │       └─ RAZÓN: Proteges contra precio subiendo
      │   │           "Pagaré máximo 1809 ETH"
      │   │
      │   └─ SI !isLong (Vendiendo/Short):
      │       │
      │       └─ acceptablePrice = currentPrice - slippageAmount
      │           │
      │           └─ RAZÓN: Proteges contra precio bajando
      │               "Venderé mínimo a 1791 ETH"
      │
      └─ SI !isIncrease (Cerrando posición):
          │
          ├─ SI isLong (Cerrando long = vendiendo):
          │   │
          │   └─ acceptablePrice = currentPrice - slippageAmount
          │       │
          │       └─ RAZÓN: Vendes, proteges contra precio bajando
          │
          └─ SI !isLong (Cerrando short = comprando):
              │
              └─ acceptablePrice = currentPrice + slippageAmount
                  │
                  └─ RAZÓN: Compras para cerrar, proteges contra precio subiendo


RETORNO:
  (acceptablePrice, currentPrice)
  │
  ├─ acceptablePrice: Precio límite con slippage
  └─ currentPrice: Precio actual del mercado


═══════════════════════════════════════════════════════════════════════════════
                     TABLA DE LÓGICA DE SLIPPAGE
═══════════════════════════════════════════════════════════════════════════════

┌─────────────┬─────────┬──────────────┬─────────────────────────────────────┐
│ Operación   │ isLong  │ isIncrease   │ Fórmula                             │
├─────────────┼─────────┼──────────────┼─────────────────────────────────────┤
│ Abrir Long  │ true    │ true         │ current + slippage (max pagas)      │
│ Abrir Short │ false   │ true         │ current - slippage (min recibes)    │
│ Cerrar Long │ true    │ false        │ current - slippage (min recibes)    │
│ Cerrar Short│ false   │ false        │ current + slippage (max pagas)      │
└─────────────┴─────────┴──────────────┴─────────────────────────────────────┘

                     OBTENER INFORMACIÓN DEL MERCADO
═══════════════════════════════════════════════════════════════════════════════

getMarket(marketAddress) → Market struct
  │
  ├─ Lee desde GMX DataStore usando keys específicas:
  │   │
  │   ├─ INDEX_TOKEN key:
  │   │   └─ keccak256(abi.encode("INDEX_TOKEN", marketAddress))
  │   │       └─ DataStore.getAddress(key) → indexToken
  │   │
  │   ├─ LONG_TOKEN key:
  │   │   └─ keccak256(abi.encode("LONG_TOKEN", marketAddress))
  │   │       └─ DataStore.getAddress(key) → longToken
  │   │
  │   └─ SHORT_TOKEN key:
  │       └─ keccak256(abi.encode("SHORT_TOKEN", marketAddress))
  │           └─ DataStore.getAddress(key) → shortToken
  │
  └─ RETORNA Market:
      {
          indexToken: 0x82aF...Bab1,    // WETH
          longToken:  0x82aF...Bab1,    // WETH
          shortToken: 0xaf88...5831     // USDC
      }


EJEMPLO (Mercado ETH/USD):
  
  Input:  marketAddress = 0x70d9...6336
  
  DataStore queries:
    ├─ INDEX_TOKEN → 0x82aF...Bab1 (WETH)
    ├─ LONG_TOKEN  → 0x82aF...Bab1 (WETH)
    └─ SHORT_TOKEN → 0xaf88...5831 (USDC)
  
  Output: Market struct con las 3 addresses


═══════════════════════════════════════════════════════════════════════════════
                     OBTENER PRECIO SIMPLE
═══════════════════════════════════════════════════════════════════════════════

getPrice(marketAddress) → uint256
  │
  ├─ getMarketPriceWithDecimals(marketAddress)
  │   └─ Retorna (rawPrice, decimals)
  │
  └─ toGMXPrice(rawPrice, decimals)
      └─ Retorna precio en formato GMX (30 decimals)


USO:
  uint256 ethPrice = gmxPrices.getPrice(ethMarketAddress);
  // ethPrice = 1800000000000000000000000000000000 (1800 * 10^30)


═══════════════════════════════════════════════════════════════════════════════
                     CONVERSIÓN DE PRECIOS
═══════════════════════════════════════════════════════════════════════════════

toGMXPrice(price, decimals) → uint256
  │
  └─ price * 10^(GMX_PRICE_DECIMALS - decimals)
      │
      └─ price * 10^(30 - decimals)


EJEMPLOS:

  Chainlink ETH/USD (8 decimals):
    Input:  1800 * 10^8
    Output: 1800 * 10^8 * 10^22 = 1800 * 10^30
  
  Chainlink BTC/USD (8 decimals):
    Input:  45000 * 10^8
    Output: 45000 * 10^8 * 10^22 = 45000 * 10^30
  
  Custom oracle (18 decimals):
    Input:  1800 * 10^18
    Output: 1800 * 10^18 * 10^12 = 1800 * 10^30


═══════════════════════════════════════════════════════════════════════════════
                     CHAINLINK INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

getChainlinkPriceFeed(tokenAddress) → address
  │
  ├─ Construye key: keccak256(abi.encode(PRICE_FEED, tokenAddress))
  │
  └─ GMX DataStore.getAddress(key)
      │
      └─ Retorna address del Chainlink aggregator


PricesLib.getPriceWithDecimals(priceFeed) → (price, decimals)
  │
  ├─ AggregatorV3Interface(priceFeed).latestRoundData()
  │   │
  │   └─ Retorna:
  │       {
  │           roundId: ...,
  │           answer: 1800 * 10^8,    // PRECIO
  │           startedAt: ...,
  │           updatedAt: ...,
  │           answeredInRound: ...
  │       }
  │
  ├─ AggregatorV3Interface(priceFeed).decimals()
  │   └─ Retorna: 8
  │
  └─ RETORNA: (1800 * 10^8, 8)


VALIDACIONES:
  ✓ priceFeed != address(0)
  ✓ answer > 0
  ✓ updatedAt reciente (previene datos obsoletos)
