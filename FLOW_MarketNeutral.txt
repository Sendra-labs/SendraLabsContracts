DESCRIPCIÓN:
  - Executor especializado para interactuar con GMX V2
  - Gestiona posiciones long/short en mercados perpetuos
  - Construye y envía órdenes complejas a GMX ExchangeRouter

DEPENDENCIAS:
  - GMX IExchangeRouter (crear órdenes)
  - GMX IOrderVault (recibir colateral)
  - Roles (autenticación)
  - DecoderLib (decodificar parámetros)
  - ProtocolStorage (datos del protocolo)

CONSTANTES:
  - USDC: 0xaf88d065e77c8cC2239327C5EDb3A432268e5831
  - WETH: 0x82aF49447D8a07e3bd95BD0d56f35241523fBab1

═══════════════════════════════════════════════════════════════════════════════
                     1. ENTRADA: FUNCIÓN EXECUTE
═══════════════════════════════════════════════════════════════════════════════

BundlesRouter → execute(
                  functionId,    // 0 = open, 1 = close
                  _data          // bytes[] parámetros encodados
                ) [payable]
  │
  ├─ VALIDACIÓN: onlyProtocol
  │   │
  │   └─ Roles.isProtocolContract(msg.sender)
  │       │
  │       ├─ SI TRUE: ✓ Continúa (msg.sender debe ser BundlesRouter)
  │       └─ SI FALSE: ✗ REVERT "SenderNotAllowed"
  │
  └─ ROUTING por functionId:
      │
      ├─ SI functionId == 0:
      │   │
      │   ├─ DecoderLib.decoder(_data) → DeFiParam[] params
      │   └─ openPositionWithEther(params)
      │
      └─ SI functionId == 1:
          │
          ├─ DecoderLib.decoder(_data) → DeFiParam[] params
          └─ closePositionV2(params)


═══════════════════════════════════════════════════════════════════════════════
                     2. ABRIR POSICIÓN (functionId = 0)
═══════════════════════════════════════════════════════════════════════════════

execute(0, _data) → openPositionWithEther(params)
  │
  ├─ PASO 1: Decodificar parámetros
  │   │
  │   └─ params[0].x = ethAmount            (uint256)
  │       params[1].x = sizeDeltaUsd        (uint256)
  │       params[2].x = acceptablePrice     (uint256)
  │       params[3].x = executionFee        (uint256)
  │       params[4].w = market              (address)
  │       params[5].w = receiver            (address)
  │       params[6].z = isLong              (bool)
  │
  ├─ PASO 2: Calcular ETH total necesario
  │   │
  │   └─ totalEthNeeded = ethAmount + executionFee
  │
  ├─ PASO 3: Construir BaseOrderUtils.CreateOrderParams
  │   │
  │   ├─ addresses:
  │   │   ├─ receiver: receiver (recibe profits)
  │   │   ├─ cancellationReceiver: receiver (recibe si se cancela)
  │   │   ├─ callbackContract: address(0) (sin callback)
  │   │   ├─ uiFeeReceiver: address(0) (sin UI fee)
  │   │   ├─ market: market (GMX market address)
  │   │   ├─ initialCollateralToken: WETH
  │   │   └─ swapPath: [] (sin swap)
  │   │
  │   ├─ numbers:
  │   │   ├─ sizeDeltaUsd: sizeDeltaUsd (tamaño posición en USD)
  │   │   ├─ initialCollateralDeltaAmount: 0 (para increase orders)
  │   │   ├─ triggerPrice: 0 (market order, no trigger)
  │   │   ├─ acceptablePrice: acceptablePrice (precio máx/min)
  │   │   ├─ executionFee: executionFee (fee para keeper)
  │   │   ├─ callbackGasLimit: 0 (sin callback)
  │   │   ├─ minOutputAmount: 0 (sin mínimo)
  │   │   └─ validFromTime: 0 (válido inmediatamente)
  │   │
  │   ├─ orderType: MarketIncrease (abrir posición)
  │   ├─ decreasePositionSwapType: NoSwap
  │   ├─ isLong: isLong (true/false)
  │   ├─ shouldUnwrapNativeToken: false
  │   ├─ autoCancel: false
  │   ├─ referralCode: bytes32(0)
  │   └─ dataList: []
  │
  ├─ PASO 4: Construir multicall para GMX
  │   │
  │   └─ multicallData[2]:
  │       │
  │       ├─ [0] IExchangeRouter.sendWnt(orderVault, totalEthNeeded)
  │       │      └─ Envía WETH al OrderVault
  │       │
  │       └─ [1] IExchangeRouter.createOrder(orderParams)
  │              └─ Crea la orden de mercado
  │
  ├─ PASO 5: Ejecutar multicall en GMX
  │   │
  │   └─ exchangeRouter.multicall{value: msg.value}(multicallData)
  │       │
  │       ├─ Envía msg.value como ETH nativo
  │       ├─ GMX wraps ETH → WETH automáticamente
  │       ├─ Transfiere WETH a OrderVault
  │       ├─ Crea orden en GMX
  │       │
  │       └─ Keepers de GMX ejecutarán la orden cuando sea posible
  │
  └─ PASO 6: Emitir evento
      │
      └─ emit PositionOpened(receiver, market, WETH, ethAmount, sizeDeltaUsd, true)


RESULTADO GMX:
  ✓ Orden creada en GMX orderbook
  ✓ Keepers ejecutarán la orden (segundos/minutos)
  ✓ Posición abierta en el mercado especificado
  ✓ Usuario puede ver posición en GMX interface

═══════════════════════════════════════════════════════════════════════════════
                     DECODIFICADOR DE PARÁMETROS
═══════════════════════════════════════════════════════════════════════════════

DecoderLib.decoder(_data) convierte bytes[] a DeFiParam[]

INPUT: _data[2]
  ├─ _data[0] = encode(types[])      // [0, 0, 0, 1, 1, 2]
  └─ _data[1] = encode(values[])     // [encodedValue1, encodedValue2, ...]

PROCESO:
  
  1. Decodifica types[] → [0, 0, 0, 1, 1, 2]
  2. Decodifica values[] → [val1, val2, val3, val4, val5, val6]
  3. Para cada tipo, crea DeFiParam:
     
     type 0 (uint256):
       ├─ param._type = 0
       ├─ param.x = decode(value, uint256)
       └─ otros campos = default
     
     type 1 (address):
       ├─ param._type = 1
       ├─ param.w = decode(value, address)
       └─ otros campos = default
     
     type 2 (bool):
       ├─ param._type = 2
       ├─ param.z = decode(value, bool)
       └─ otros campos = default

OUTPUT: DeFiParam[] params
  └─ Acceso a valores por índice: params[i].x, params[i].w, params[i].z


EJEMPLO OPEN POSITION:

  types:  [0,       0,          0,             0,          1,      1,        2]
  values: [ethAmt,  sizeDelta,  acceptPrice,   execFee,    market, receiver, isLong]
           │
           └─ params[0]._type = 0, params[0].x = ethAmount

                     GMX V2 - CÓMO FUNCIONA LA ORDEN
═══════════════════════════════════════════════════════════════════════════════

1. Usuario/Protocolo → MarketNeutral.openPositionWithEther()
   │
   └─ Construye CreateOrderParams con todos los detalles

2. MarketNeutral → GMX ExchangeRouter.multicall()
   │
   ├─ sendWnt(orderVault, amount)
   │   └─ Transfiere WETH al OrderVault
   │
   └─ createOrder(params)
       └─ GMX crea orden en su sistema

3. GMX Keepers (off-chain):
   │
   ├─ Monitorean ordersBook
   ├─ Cuando condiciones son correctas
   └─ Ejecutan la orden

4. GMX Execution:
   │
   ├─ Valida precio vs acceptablePrice
   ├─ Abre/cierra posición en el mercado
   ├─ Transfiere colateral al usuario
   └─ Llama callback si está configurado

5. Callback (opcional):
   │
   └─ GMX → MarketNeutral.afterOrderExecution()
       └─ Protocolo puede calcular PnL y actualizar storage


VALIDACIONES GMX:
  
  ✓ acceptablePrice: Protege contra slippage excesivo
  ✓ executionFee: Debe ser suficiente para keeper
  ✓ Saldo en OrderVault: Debe tener fondos
  ✓ Market exists: Mercado debe estar activo


═══════════════════════════════════════════════════════════════════════════════
                     ESTRUCTURA DeFiParam
═══════════════════════════════════════════════════════════════════════════════

struct DeFiParam {
    uint8 _type;     // Tipo de dato (0=uint, 1=address, 2=bool, etc)
    bytes v;         // Para bytes
    address w;       // Para address
    uint256 x;       // Para uint256
    int256 y;        // Para int256
    bool z;          // Para bool
}

USO:
  
  Para uint256: params[i].x
  Para address: params[i].w
  Para bool:    params[i].z
  Para int256:  params[i].y
  Para bytes:   params[i].v
